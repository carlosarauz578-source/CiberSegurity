# Proyecto: Contenedores Aislados con Docker y Podman

## 📌 Descripción
Este proyecto documenta la creación y administración de contenedores aislados utilizando **Docker** y **Podman** en un entorno **Kali Linux**.  
El objetivo principal es correr una API dentro de un contenedor y realizar pruebas de seguridad controladas y **100% legales**, incluyendo ataques simulados hacia servicios habilitados (ejemplo: Google en entorno de laboratorio).

## 🚀 Objetivos
- Aprender a levantar contenedores aislados en Docker y Podman.
- Ejecutar una API dentro de un contenedor.
- Probar ataques controlados desde Kali contra los contenedores levantados.
- Documentar resultados y buenas prácticas de seguridad.

## 🛠️ Tecnologías utilizadas
- **Docker** y **Podman** → gestión de contenedores.
- **Kali Linux** → entorno de pruebas de seguridad.
- **Scripts de ataque** → pruebas controladas (SQLi, XSS, fuerza bruta, etc.).
- **Google habilitado como objetivo de prueba** → únicamente en entorno legal y cerrado.
